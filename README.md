# NFC-карты для заведений

Пластиковая карта на столе → касание → страница со ссылками заведения.
Метка хранит только ссылку, сама страница лежит здесь.

## Что где лежит

```
_template/index.html   шаблон, из него штампуются клиенты
new-client.ps1         скрипт: создаёт папку клиента из шаблона
dostar/index.html      демо-заведение (пример)
```

## Новый клиент — одна команда

```powershell
.\new-client.ps1 -Slug bereke -Name "Кафе Береке" `
    -Instagram "https://instagram.com/bereke_shymkent" `
    -TikTok    "https://tiktok.com/@bereke_shymkent" `
    -Gis       "https://go.2gis.com/xxxxx" `
    -Menu      "https://instagram.com/bereke_shymkent"
```

`-Slug` — короткое латинское имя, оно попадёт в ссылку.
`-Initials` можно не указывать: скрипт возьмёт первые буквы двух первых слов.
`-City` по умолчанию Шымкент.

Ссылку на 2GIS брать так: карточка заведения → «Поделиться» → короткая ссылка `go.2gis.com/...`.
Чтобы вести сразу на форму отзыва, добавь в конец `/tab/reviews`.

## Публикация (GitHub Pages, бесплатно и без срока)

Делается один раз, через сайт, командная строка не нужна.

1. Зарегистрироваться на github.com
2. **New repository** → имя `nfc-cards` → **Public** → Create
3. На странице репозитория **Add file → Upload files**, перетащить туда всё содержимое этой папки
4. **Settings → Pages** → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save
5. Подождать 1–2 минуты

Адрес страницы клиента получится:

```
https://madiyar77758.github.io/nfc-cards/dostar/
```

Этот адрес и пишется в метку.

## Запись метки

NFC Tools → вкладка **ЗАПИСЬ** → Добавить запись → **URL** → вставить адрес целиком
с `https://` → **Записать** → приложить карту к телефону сзади, держать до звука.

**Блокировку («только для чтения») не включать.** Она необратима.

## Проверка перед выдачей клиенту

- прочиталась на Android
- прочиталась на iPhone (XS и новее — просто разблокированным экраном)
- прочиталась **на том самом столе**: металлическая столешница или поднос глушат NFC
- все четыре ссылки открываются и ведут куда надо

## Когда появится свой домен

Сейчас в метку пишется прямой адрес GitHub Pages. Как только будет домен,
переходим на схему с редиректом:

```
карта → домен.kz/dostar → (редирект) → реальная страница
```

Тогда при любом переезде хостинга или смене ссылок клиента карты трогать не придётся.
Поэтому первые метки **не блокировать** — их ещё предстоит перезаписать один раз.

## Про кодировку

`new-client.ps1` обязан лежать в UTF-8 **с BOM** — иначе PowerShell 5.1 читает его
в системной кодировке и кириллица разваливается. HTML, наоборот, пишется
**без BOM** — с ним некоторые хостинги отдают мусор в начале страницы.
