# NFC-карты для заведений

Пластиковая карта на столе → касание → страница со ссылками заведения.
Метка хранит только ссылку, сама страница лежит здесь.

## Что где лежит

```
_template/index.html   шаблон, из него штампуются клиенты
new-client.ps1         скрипт: создаёт папку клиента из шаблона
dostar/index.html      демо-заведение (пример)
```

## Новый клиент — одна команда

```powershell
.\new-client.ps1 -Slug bereke -Name "Кафе Береке" `
    -Instagram "https://instagram.com/bereke_shymkent" `
    -TikTok    "https://tiktok.com/@bereke_shymkent" `
    -Gis       "https://go.2gis.com/xxxxx" `
    -Menu      "https://instagram.com/bereke_shymkent"
```

Необязательные, но сильно улучшают страницу:

```powershell
    -Hours    "10:00-00:00"    плашка «Открыто до 00:00», считается на телефоне
    -WifiName "Bereke_Guest"   строка Wi-Fi
    -WifiPass "bereke2026"     пароль копируется одним касанием
    -Phone    "+7 701 234 56 78"
    -Review   "https://2gis.kz/.../tab/reviews"   сразу на отзывы
```

Не задал — строки просто не будет, пустой рамки не останется.

`-Slug` — короткое латинское имя, оно попадёт в ссылку.
`-Initials` можно не указывать: скрипт возьмёт первые буквы двух первых слов.
`-City` по умолчанию Шымкент.

Ссылку на 2GIS брать так: карточка заведения → «Поделиться» → короткая ссылка `go.2gis.com/...`.
Чтобы вести сразу на форму отзыва, добавь в конец `/tab/reviews`.

## Три языка

Русский, казахский, узбекский. Переключатель в шапке обеих страниц,
выбор запоминается и переносится с главной на меню.

Тексты лежат прямо в разметке рядом друг с другом:

```html
<span class="i18n">
  <i lang="ru">Плов</i>
  <i lang="kk">Палау</i>
  <i lang="uz">Ош</i>
</span>
```

Показ переключает CSS по атрибуту `data-lang` на `<html>`. Если JavaScript
отключён, страница остаётся на русском и полностью читаема.

При первом заходе язык берётся из настроек телефона: казахский телефон
открывает казахскую версию сам.

**Узбекский набран кириллицей** — так учат в узбекских школах Казахстана.
Если решишь перейти на латиницу (стандарт Узбекистана), это отдельная правка
всех строк `lang="uz"`.

## Клиент с настоящим меню и админкой (`xamidoo`)

Шаблон `_template` держит меню прямо в разметке: чтобы поменять цену, нужно
править HTML. Для заведений с большим меню сделана вторая схема — данные
отдельно от вёрстки, плюс админка, в которой кафе меняет цены само.

```
xamidoo/index.html        карточка-встреча
xamidoo/menu/index.html   меню, рисуется из данных
xamidoo/menu/photo/       фотографии блюд
xamidoo/admin/            админка: блюда, цены, акции, ссылки заведения
xamidoo/card/             макет карты для печати + qr.svg
xamidoo/data/menu.json    сами данные
xamidoo/app/config.js     адрес API — единственное, что правится руками
api/                      воркер Cloudflare + инструкция
```

**Пока воркер не развёрнут** сайт работает: меню читается из `data/menu.json`,
а админка открывается в локальном режиме и отдаёт готовый файл кнопкой «Файл».
Вы кладёте его в `data/` и коммитите.

**После развёртывания** (см. `api/README.md`, минут пятнадцать) админка просит
пароль и сохраняет по-настоящему — кафе меняет цены с телефона, у гостей
обновляется в течение 30 секунд. Один воркер обслуживает всех клиентов сразу,
так что второму заведению деплой уже не нужен.

Меню всегда падает обратно на файл, если воркер недоступен: гость в худшем
случае увидит вчерашние цены, но не пустой экран.

### Что умеет админка

- блюда: добавить, удалить, переименовать, поменять цену и описание,
  отметить «хит», временно скрыть, переставить местами
- разделы: добавить, переименовать на трёх языках, переставить, удалить
- акции: скидка в процентах на всё меню, на разделы или на отдельные блюда,
  с датами, днями недели и часами — «бизнес-ланч −20% с 12:00 до 16:00
  по будням» настраивается за минуту и включается сам
- заведение: название, адрес, часы, телефон, WhatsApp, 2ГИС, Instagram,
  TikTok, Wi-Fi. Пустое поле = строки на карточке нет

Фотографии кладутся файлами в `menu/photo/`, в поле «Фото» пишется имя файла
(или полный адрес картинки). Загрузки прямо из админки нет — она потребует
Cloudflare R2, это отдельная настройка.

## Публикация (GitHub Pages, бесплатно и без срока)

Делается один раз, через сайт, командная строка не нужна.

1. Зарегистрироваться на github.com
2. **New repository** → имя `nfc-cards` → **Public** → Create
3. На странице репозитория **Add file → Upload files**, перетащить туда всё содержимое этой папки
4. **Settings → Pages** → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save
5. Подождать 1–2 минуты

Адрес страницы клиента получится:

```
https://madiyar77758.github.io/nfc-cards/dostar/
```

Этот адрес и пишется в метку.

## Печать: из чего делать обёртку

### Главное ограничение

**Фольга и металлизированные краски глушат NFC.** Антенна метки лежит внутри
пластика, и любой металлический слой сверху экранирует её — карта перестаёт
читаться. Никакого золотого тиснения, серебра, «металлик» и голограмм.

Бумага, винил, обычные краски и ламинация NFC не мешают.

### Если печатаем сами

**Сначала посмотри, какой у тебя принтер — струйный или лазерный.**
Самоклейка бывает под каждый, и перепутать нельзя: на лазерной бумаге
струйные чернила не сохнут и мажутся, а покрытие струйной бумаги плавится
в лазерном принтере и портит барабан.

Что купить (искать на Kaspi по этим словам):

| Что | Запрос | Примерно |
|---|---|---|
| Самоклеящаяся бумага A4, матовая | «самоклеящаяся бумага А4 матовая» + тип принтера | 2 000 ₸ / 50 листов |
| Плёнка холодной ламинации, матовая | «пленка самоклеящаяся матовая А4» | 2 000 ₸ / 50 листов |
| Угловой дырокол R3 | «угловой дырокол» или «закруглитель углов» | 2 000–4 000 ₸ |
| Линейка металлическая 40 см | «линейка металлическая» | 1 000 ₸ |
| Нож канцелярский + коврик для резки A3 | «мат для раскроя A3» | 2 500 ₸ |

Разовые вложения около **10 000 ₸**, дальше примерно **50 ₸ на карту**.

Порядок работы: печать → наклеить плёнку **до** резки → резать по линейке →
скруглить углы дыроколом.

Скруглённые углы важнее, чем кажется: именно они отличают «изделие»
от «вырезано дома ножницами».

### Три способа, по возрастанию цены

**1. Наклейка на карту** — дешевле всего, годится для первых клиентов.
Печать на белом виниле или полипропилене, матовая ламинация.
Делает любое рекламное агентство в Шымкенте.

**2. УФ-печать прямо по пластику** — выглядит дороже, не отклеивается.
На чёрной карте нужна подложка белилами, иначе цвета утонут.
Дороже наклейки примерно вдвое.

**3. Готовые карты с печатью и чипом с завода** — лучшее качество и цена
за штуку, но тираж от нескольких сотен. Имеет смысл, когда пойдут постоянные
заказы.

### Что отдавать в типографию

| Параметр | Значение |
|---|---|
| Размер | 85,6 × 54 мм (как банковская карта) |
| Скругление углов | 3,18 мм |
| Вылеты под рез | 2 мм с каждой стороны |
| Безопасная зона | 4 мм от края — внутрь не заводить текст |
| Наклейка | на 2–3 мм меньше карты, иначе края задираются |
| Цвет | CMYK |
| Ламинация | **матовая** — глянец бликует, QR перестаёт ловиться |
| QR | не меньше 22 мм, тёмный на светлом |

**Файл:** открой `<slug>/card/` в браузере и печатай в PDF
(Ctrl+P → «Сохранить как PDF»). Шрифты вшиваются сами, вектор сохраняется —
типографии этого достаточно. Отдельно можно отдать `qr.svg`, он тоже вектор.

### Перед тиражом

Напечатай **одну** карту, наклей и проверь на телефоне: читается ли NFC
через наклейку и ловится ли QR при обычном освещении в зале. Только потом
запускай остальные.

## Запись метки

NFC Tools → вкладка **ЗАПИСЬ** → Добавить запись → **URL** → вставить адрес целиком
с `https://` → **Записать** → приложить карту к телефону сзади, держать до звука.

**Блокировку («только для чтения») не включать.** Она необратима.

## Проверка перед выдачей клиенту

- прочиталась на Android
- прочиталась на iPhone (XS и новее — просто разблокированным экраном)
- прочиталась **на том самом столе**: металлическая столешница или поднос глушат NFC
- все четыре ссылки открываются и ведут куда надо

## Свой домен: menyukz.com

Домен куплен 26 августа 2026 в Cloudflare Registrar (~$10.5 в год, продление
по той же цене). В метку и в QR пишется **только он**, прямой адрес GitHub
Pages в карты больше не попадает:

```
карта → menyukz.com/xamidoo/ → воркер go/ забирает страницу с хостинга
        и отдаёт её сам → в строке у гостя остаётся menyukz.com
```

Это **прокси, а не перенаправление**. Редирект браузер отрабатывает и
показывает конечный адрес — гость видел бы `madiyar77758.github.io/...`,
и весь смысл своего домена терялся. Прокси отдаёт страницу от имени домена,
поэтому адрес остаётся коротким и своим.

Куда смотрит каждый адрес, решает `go/worker.js` — таблица `PLACES` в начале
файла. Новое заведение = одна строка плюс `npx wrangler deploy` из папки `go/`.
Через прокси идут и страницы, и стили, и данные, и фотографии; статика лежит
в кэше Cloudflare пять минут, чтобы не ездить за каждым снимком до GitHub.

**Косая на конце обязательна** — `menyukz.com/xamidoo/`, а не `/xamidoo`.
Без неё относительные ссылки страницы считались бы от корня домена, поэтому
воркер сам исправляет адрес, но это лишний переход. В метку пишем сразу с ней.

Теперь переезд хостинга не требует объезжать кафе с телефоном. Блокировку
метки (read-only) всё равно не включайте: она необратима.

## Про кодировку

`new-client.ps1` обязан лежать в UTF-8 **с BOM** — иначе PowerShell 5.1 читает его
в системной кодировке и кириллица разваливается. HTML, наоборот, пишется
**без BOM** — с ним некоторые хостинги отдают мусор в начале страницы.
